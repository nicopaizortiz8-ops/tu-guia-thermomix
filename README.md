# Yo Uso Cocina

Build a premium, modern, highly interactive website/web app called “Yo Uso Thermomix”.

This is NOT meant to look like a generic Thermomix corporate website or a basic sales landing page.

The website belongs to an independent Thermomix consultant in Guatemala who already has an audience on Instagram under Yo Uso Thermomix, regularly creates cooking content, hosts live cooking sessions, shares recipes, and sells Thermomix products directly to customers.

The primary business objective is:

Turn social-media visitors into engaged users, then into WhatsApp leads and ultimately Thermomix customers.

The secondary long-term objective is to build a useful cooking platform that users return to regularly through recipes, AI tools, meal planning, savings calculators, and exclusive content.

1. PRODUCT VISION

The website should feel like a combination of:

Premium cooking/lifestyle website

Personal cooking brand

Modern recipe platform

AI-powered kitchen assistant

Thermomix education platform

Sales funnel

It should NOT feel like:

A corporate appliance website

An aggressive ecommerce store

A generic AI chatbot

A template-based cooking blog

A website whose only purpose is “Buy Thermomix”

The user should initially think:

“This is a beautiful and genuinely useful cooking platform.”

“This person really knows how to use Thermomix.”

Eventually:

“If I buy a Thermomix, I want to buy it from her.”
